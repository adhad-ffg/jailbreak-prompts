# jailbreak-prompts

A repository for collecting and studying LLM jailbreak prompts.

## Purpose

This repository collects and organizes publicly available jailbreak techniques and prompts for research and educational purposes, in order to examine how the safety mechanisms of large language models (LLMs) can be bypassed.
